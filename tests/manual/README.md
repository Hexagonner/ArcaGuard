# Phase 0 로컬 브라우저 검증

검증일: 2026-10-24 (Asia/Seoul).
대상: `http://127.0.0.1:5174/preview.html` (호스트의 개발 서버).

- 초기에는 오른쪽 아래 ArcaGuard 버튼만 표시.
- 버튼 클릭으로 패널 열림. 감시 꺼짐 / 자동 이동 꺼짐 / 관리자 권한 미검증 표시.
- 화면 동작 확인 클릭: `화면 응답 정상 · 사이트 요청 없이 확인했습니다.` 표시.
- Escape로 패널 닫힘, ArcaGuard 버튼으로 포커스 복원.
- 1280×720 및 390×844 화면에서 패널/버튼/상태 표시 확인.
- 좁은 화면에서도 가로 잘림 없이 버튼 접근 가능. 검사 후 화면 크기 복원.

증거: `phase0-desktop.png`, `phase0-narrow.png`.
