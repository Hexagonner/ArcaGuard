# Phase 0 로컬 브라우저 검증

검증일: 2026-10-24 (Asia/Seoul).
대상: `http://127.0.0.1:5174/preview.html` (호스트의 개발 서버).

- 초기에는 오른쪽 아래 ArcaGuard 버튼만 표시.
- 버튼 클릭으로 패널 열림. 감시 꺼짐 / 자동 이동 꺼짐 / 관리자 권한 미검증 표시.
- 화면 동작 확인 클릭: `화면 응답 정상 · 사이트 요청 없이 확인했습니다.` 표시.
- Escape로 패널 닫힘, ArcaGuard 버튼으로 포커스 복원.
- 1280×720 및 390×844 화면에서 패널/버튼/상태 표시 확인.
- 좁은 화면에서도 가로 잘림 없이 버튼 접근 가능. 검사 후 화면 크기 복원.

증거: `phase0-desktop.png`, `phase0-narrow.png`.
이는 로컬 브라우저 검증이며 Tampermonkey 설치나 실사이트 검증은 아니다.

## 실제 Chrome 연결 및 위치 보완 검증

2026-10-24, 실제 Chrome 확장 연결, `http://127.0.0.1:5173/preview.html`.

- `chrome-local-preview.png`: 버튼/패널/화면 동작 확인 정상, 안전한 상태 표시 확인.
- 새 소스를 명시적으로 새로고침한 뒤 버튼 드래그, 패널 열린 상태 유지, 저장 안내 확인.
- 버튼 좌상단 (104, 19)로 이동한 후 새로고침: 동일 좌표 복원, 패널은 닫힌 상태.
- Alt + 오른쪽 방향키: 좌표 (114, 19)로 10px 이동 확인.
- 기본 위치로 되돌리기: 오른쪽 아래 복귀와 안내 확인.
- 다시 왼쪽으로 드래그해 위치 사용자 지정, `chrome-custom-position.png` 저장.
- 당시 Chrome viewport가 약 1532×234로 매우 낮았으며, 패널 내부 스크롤로
  안내/초기화 버튼 접근을 확인했다. 전체 크기 변경 대응은 자동 단위 테스트에서도 확인했다.

Tampermonkey 내부 화면과 arca.live 직접 접근은 도구 정책으로 차단됐다.
사용자가 실제 아카라이브에서 버튼/패널/응답이 정상이라고 확인했으며,
이는 신규 위치 기능의 실사이트 직접 검증이나 관리자 권한 검증을 뜻하지 않는다.
