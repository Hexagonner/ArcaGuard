- 채널: https://arca.live/b/prlvate (`prlvate` 표기 그대로).
- 광고 판정 조건을 충족한 미처리 글의 이동 대상 이름: `TEST`.

- TEST 탭 존재/ID/의미, 실제 이동 권한, 신고 화면은 아직 확인하지 않았다.
- 이번 요구사항 반영에서 실사이트를 열거나 신고/글을 읽거나 변경하지 않았다.
- 지정 채널은 후속 테스트 범위이며 개별 글 이동 승인이나 Phase 1 승인이 아니다.

후속 승인된 조사에서는 신고 행의 실제 링크/신고자 표시 이름/안정적 계정 식별값/내용,
원시 건수와 고유 집계 가능성, 익명 신고/목록 페이지/철회 상태, 현재 글머리와 타 관리자
이동 이력의 제공 여부를 확인해야 한다. 사이트가 반복 신고를 자체 제한하는지도 현재 미확인이다.
필드별 근거와 날짜가 생기기 전까지 신뢰할 수 있는 고유 신고자 카운터라고 보고하지 않는다.
