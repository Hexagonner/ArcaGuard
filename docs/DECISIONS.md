  위치 조정 시도 때문에 브라우저 방문 기록이 이동하지 않도록 한다.
- 실제 Chrome localhost에서 UI/숨김 복구/고정 보존을 검증했다. 확장 메뉴는 Mock/번들 검사로만 검증하며
  실제 사이트/확장 선택 성공으로 보고하지 않는다. 새 개발 메타데이터 반영에는 스크립트 업데이트가 필요하다.

  운영 선택자/어댑터/실제 HTML Fixture를 만들어 동작하는 것처럼 제시하지 않는다.
- 참고 코드의 nickname 기반 UID, 누락 값을 일반/익명/현재 시각으로 채우기,
  동명 글머리 덮어쓰기, 보이는 목록 교체를 ArcaGuard 조치 경로에 그대로 가져오지 않는다.
- 사용자가 신고 목록 주소/열/테스트 행과 상세 사유 필드 존재를 제공했다.
  작성자/신고자를 구별하고 상세에서 실제 사유를 읽어야 한다. 두 계정 역할을 두 신고로 세지 않는다.
- 제공된 번호 포함 프로필은 계정 키 후보다. 번호 불변성/닉네임 변경/익명 처리는 직접 검증 전이다.
  상세 사유의 존재와 실제 `광고` 포함 여부를 구별한다.
- 공개 저장소에는 계정명/개별 신고 ID를 보관하지 않고 모든 행 값을 합성한 JSON 계약 예시만 추가한다.
  이는 사용자 제공 텍스트의 익명화 구조이며 DOM 캡처/수집기 성공 증거가 아니다.
- Phase 1은 1차 조사를 기록하되 실제 DOM/권한/완전성/글머리/백그라운드 변경 경로는 미검증으로 유지한다.
