  로컬 UI 진입점을 `/preview.html`로 둔다. 개발 설치 URL도 실제 응답으로 확인한다.
- 현재 Node 24.14.0과 호환되는 jsdom 29.1.1 사용. jsdom 30.1.3은 Node 24.15+
  요구로 선택하지 않았다. 다른 의존성도 조회한 호환 버전을 고정한다.
- 명세서 원문은 `docs/REQUIREMENTS.md`에 보존한다. 외부 코드는 복사하지 않았다.

  패널은 버튼의 위/아래 중 공간이 많은 방향에 열며 넘치는 내용은 패널 안에서 스크롤한다.

  전용 키 `arcaguard.ui.position.v1`에 version/x/y만 저장한다. 일반 설정 저장소 구현은 후속 단계다.

- 위치 자료는 비신뢰 입력으로 검증한다. 버전/형식/좌표 범위 오류는 기본 위치를 사용한다.
  저장 거부 시 화면 이동은 허용하고 영구 저장 실패를 안내한다. 인증/신고/게시물 자료는 저장하지 않는다.
- 개발 화면 직접 검증과 실제 사이트 사용자 확인을 분리하며 브라우저 도구의 접속 차단을 우회하지 않는다.

## 2026-10-24 — 위치 고정·버튼 숨김 및 전용 관리자 화면

- 사용자의 이번 지시는 버튼 위치 고정/표시 토글 및 복구 가능한 전용 관리자 UI 구현 승인으로 적용한다.
  Phase 5의 채널/주제/신고 설정이나 관리 쓰기 승인은 아니다.
- 별도 서버나 추측한 사이트 관리자 경로 대신 Shadow DOM 안에 전체 화면 설정을 만든다.
  자동으로 열지 않고 명시적 버튼/단축키/메뉴 요청에만 연다. 관리자 권한 확인 화면으로 안내하지 않는다.
- 숨김 후 접근 경로로 Alt + Shift + G와 `GM_registerMenuCommand` 메뉴를 제공한다.
  배포 grant는 메뉴 등록 하나만 허용하며 빌드 검사에서 개수/이름을 확인한다.
  개발 환경은 공식 vite-plugin-monkey client의 sandbox bridge를 runtime adapter에서 사용한다.
- 위치 저장 키는 보존하고 `arcaguard.ui.preferences.v1`에 version/visible/locked만 별도로 저장한다.
  불완전/잘못된 자료는 표시 ON/고정 OFF이며 저장 거부 시 현재 화면 적용과 안내를 제공한다.
- 위치 고정은 드래그/키보드/초기화를 잠근다. 고정 상태의 Alt + 방향키도 기본 동작을 막아
  위치 조정 시도 때문에 브라우저 방문 기록이 이동하지 않도록 한다.
- 실제 Chrome localhost에서 UI/숨김 복구/고정 보존을 검증했다. 확장 메뉴는 Mock/번들 검사로만 검증하며
  실제 사이트/확장 선택 성공으로 보고하지 않는다. 새 개발 메타데이터 반영에는 스크립트 업데이트가 필요하다.
